## Дипломный проект. Задание 3: веб-приложение

### Автотесты для проверки веб-приложения заказа бургеров Stellar Burgers 

### Реализованные сценарии

Созданы автотесты постарнично покрывающие следующие сценарии:

Восстановление пароля `test_login.py`

* переход на страницу восстановления пароля по кнопке «Восстановить пароль»,
* ввод почты и клик по кнопке «Восстановить»,
* клик по кнопке показать/скрыть пароль делает поле активным — подсвечивает его.

Личный кабинет `test_profile.py`

* переход по клику на «Личный кабинет»,
* переход в раздел «История заказов»,
* выход из аккаунта.

Проверка основного функционала `test_constructor.py`

* переход по клику на «Конструктор»,
* переход по клику на «Лента заказов»,
* если кликнуть на ингредиент, появится всплывающее окно с деталями,
* всплывающее окно закрывается кликом по крестику,
* при добавлении ингредиента в заказ, увеличивается каунтер данного ингредиента
* залогиненный пользователь может оформить заказ.

Раздел «Лента заказов» `test_order_feed.py` 

* если кликнуть на заказ, откроется всплывающее окно с деталями,
* заказы пользователя из раздела «История заказов» отображаются на странице «Лента заказов»,
* при создании нового заказа счётчик Выполнено за всё время увеличивается,
* при создании нового заказа счётчик Выполнено за сегодня увеличивается,
* после оформления заказа его номер появляется в разделе В работе.

### Структура проекта

- `utils` - пакет содержащий утилиты, например, фабрику браузеров
- `src` - пакет, содержащий тестовые данные и вспомогательные функции
- `locators` - пакет с локаторами разделенными по страницам в соответствии с паттерном проектирования POM (Page Object Model)
- `pages` - пакет с функциями необходимых для работы с локаторами, разделенные по страницам в соответствии с POM
- `tests` - пакет, содержащий тесты разделенные по страницам в соответствии с POM
- `conftest.py` - содержит фикстуры pytest необходимые для тестов
- `requirements.txt` - файл зависимостей
- `allure-results-chrome` - Allure отчёт по тестам запущенных в Google Chrome
- `allure-results-firefox` - Allure отчёт по тестам запущенных в Mozila Firefox


### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

Также необходим доступ к самому сервису: https://stellarburgers.nomoreparties.site/

**Запуск автотестов и просмотр Allure отчёта в Chrome**

>  `$ pytest tests/ --browser=chrome --headless -v --alluredir=allure-results-chrome`

>  `$ allure serve allure-results-chrome`

**Запуск автотестов и просмотр Allure отчёта в Firefox**

>  `$ pytest tests/ --browser=firefox --headless -v --alluredir=allure-results-firefox`

>  `$ allure serve allure-results-firefox`

* для запуска с отображением браузера запускать без параметра --headless
